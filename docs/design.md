# Wordle в Telegram — согласованные решения

## Назначение

- Создать Telegram-бота с игрой Wordle в HTML-виджете внутри сообщения.
- Первая версия предназначена для личного использования.
- Целевые клиенты первой версии — Telegram Desktop на Windows и Telegram на Android (уточнено при подготовке плана).

## Правила

- Язык — русский.
- Загаданное слово состоит из пяти букв.
- Для загаданных слов используется небольшой список простых существительных в единственном числе и именительном падеже, без имён и редких терминов.
- Ё и Е считаются одной буквой. В словах и на игровой клавиатуре используется Е.
- На угадывание даётся шесть попыток.
- Любая отправленная последовательность из пяти русских букв расходует попытку; проверять наличие предложенного слова в словаре не нужно.
- Подсказки соответствуют классической Wordle: буква на своём месте, буква есть на другой позиции, буква отсутствует. Повторяющиеся буквы учитываются по числу вхождений в загаданное слово.
- Играть можно свободно, без ограничения одной партией в сутки. Новую игру можно начать в любой момент.
- Долговременного сохранения прогресса нет. При кратком сворачивании Telegram партия остаётся; после полного закрытия и перезапуска Telegram начинается новая партия.

## Жизненный цикл партии

- Слово, принятые попытки и незавершённый ввод находятся во временном хранилище `sessionStorage` конкретного сообщения на конкретном устройстве.
- Это позволяет восстановить партию после пересоздания виджета при прокрутке или нехватке памяти, а также продолжить игру после краткого сворачивания приложения.
- Временное хранилище очищается при перезапуске приложения Telegram. Простое закрытие окна без завершения приложения не считается перезапуском.
- На другое устройство партия не переносится. Бот не хранит игровой прогресс.
- Основание: [Telegram Widgets — Storage, links and haptics](https://core.telegram.org/bots/widgets#storage-links-and-haptics) и [Lifecycle](https://core.telegram.org/bots/widgets#lifecycle).

## Запуск

- Для первой версии бот запускается локально на компьютере пользователя и отвечает, пока программа работает.
- Постоянный сервер на этом этапе не нужен.

## Согласованное устройство первой версии

- Команда `/start` отправляет сообщение с игровым виджетом.
- Внутри виджета находятся поле 6 × 5, русская клавиатура с кнопками ввода и удаления, кнопка «Новая игра» и строка результата.
- Цвета интерфейса учитывают светлую и тёмную тему Telegram. Подсказки имеют классические зелёный, жёлтый и серый цвета.
- После победы или шестой неудачной попытки показывается загаданное слово. Новая игра очищает поле и выбирает новое слово.
- Небольшой список ответов и игровая логика включаются в сам виджет. Нажатия обрабатываются на устройстве без обращения к боту.
- Бот написан на Python с использованием aiogram 3.x; получение команд — через long polling средствами aiogram. Отправка HTML-виджета выполняется через сессию этой библиотеки. Если в закреплённой версии ещё нет готового метода `sendWidget`, используется небольшое расширение `TelegramMethod` внутри проекта. Отдельный веб-сайт и база данных для этого подхода не требуются.
- Итоговый HTML проверяется на лимиты Telegram: 32 768 байт UTF-8 и 4096 байт после сжатия zlib уровня 9.
