## 10 ноября 2026 года — статичный макет интерфейса

Файл: [bot/widgets/wordle_widget.html](../bot/widgets/wordle_widget.html). По запросу пользователя добавлены только HTML и встроенный CSS. Поле и клавиатура показывают пример партии; кнопки не меняют состояние. Игровую логику пользователь реализует самостоятельно.

- Одноразовая проверка через `.\.venv\Scripts\python.exe -` из корня проекта завершилась с кодом 0: HTML5 doctype, корректная вложенность, шесть строк по пять клеток, все 32 русские буквы без Ё по одному разу на клавиатуре, кнопки ввода и удаления. Скриптов, обработчиков событий и внешних ресурсов нет.
- Размер готового файла: **13 752 байта UTF-8**, **2945 байт zlib уровня 9**. Оба ограничения соблюдены. Размер относится только к макету без будущей игровой логики и списка ответов.
- Браузерный просмотр выполнен локально. При ширине 320 px высота игрового блока — 507,75 px; при 380 px — 544,22 px. Ширина документа равна ширине окна в обоих случаях, горизонтальной прокрутки нет.
- Просмотрены тёмная и светлая палитры. Для светлой использовалась временная копия с отключённым тёмным CSS-медиаправилом; системная тема не менялась. Автоматическое соответствие теме Telegram пока не проверено.
- Первый запуск локального просмотра из ограниченного окружения был недоступен; повторный запуск с разрешённым локальным сетевым доступом позволил открыть страницу и выполнить проверки. Временная копия удалена, сервер просмотра остановлен после проверки.
- Полный автоматический набор недоступен: `tests/python`, `tests/js` и `wordle_bot.widget` ещё отсутствуют. Проверки игровой логики не выполнялись, поскольку её нет в макете.
- Бот не запускался. Доставка виджета и приёмка в Telegram на Windows и Android не выполнялись; этапы плана остаются открытыми.

## 10 ноября 2026 года — разделение HTML и CSS

Файлы: [HTML](../bot/widgets/wordle_widget.html) и [CSS](../bot/widgets/wordle_widget.css).

- Встроенный блок стилей перенесён в соседний `wordle_widget.css`, в HTML добавлен относительный `<link rel="stylesheet">`. При переносе одноразовыми проверками подтверждено сохранение всего CSS с изменением только общего отступа и сохранение остального HTML. JavaScript не добавлялся.
- Локальный браузер загрузил HTML и CSS с ответом HTTP 200; таблица стилей содержит 40 правил верхнего уровня. При ширине 320 px высота игрового блока по-прежнему 507,75 px, ширина документа — 320 px; внешний вид сохранён.
- Размеры исходников: HTML — 7491 байт UTF-8, CSS — 4737 байт UTF-8. При проверочном встраивании CSS в HTML только в памяти получено 12 196 байт UTF-8 и 2886 байт zlib уровня 9, что укладывается в ограничения плана. Готовая сборка и постоянный сборщик не создавались; исходный HTML с `<link>` предназначен для просмотра в браузере.
- Одноразовая проверка через `.\.venv\Scripts\python.exe -`: структура HTML, поле 6 × 5, русская клавиатура, существование CSS по относительной ссылке, отсутствие JavaScript и локальные ссылки изменённых документов. Сервер просмотра остановлен после проверки.
- Полный автоматический набор по-прежнему недоступен из-за отсутствия `tests/python`, `tests/js` и `wordle_bot.widget`. Бот не запускался, приёмка в Telegram на Windows и Android не выполнялась.
